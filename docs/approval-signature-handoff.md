# 승인 권한 제거 — 서명만으로 승인 (백엔드 변경 요청)

작성일: 2026-11-16

## 현재 문제

`POST /api/jobs/{id}/approval/approve` 와 `/reject` 가 **403**을 반환합니다.
서버가 "보안책임자·팀리드 역할"과 "개발자 본인 승인 금지"를 검사하고 있기 때문입니다.
이 역할 체계는 요구사항에 없으며, 프론트에서는 관련 안내 문구를 모두 제거했습니다.

재현: sample_java6 (`jongha021229/sample_java6`, High 1건 → 승인 필요)을 실행한 사람이 직접 승인하면 403이 납니다.

## 요청

1. approve/reject에서 **역할(보안책임자·팀리드) 검사와 본인 승인 금지 검사를 제거**해 주세요.
   로그인한 사용자라면 누구나 승인·거부할 수 있어야 합니다.
2. **서명 = 승인자 이름**입니다. 프론트는 요청 본문에 다음을 보냅니다.
   ```json
   { "reason": "[승인자: 홍길동] 검토 후 수용", "approver_name": "홍길동" }
   ```
   - `approver_name`이 비어 있으면 `400`으로 거부해 주세요(서명 필수).
   - 감사 로그(`GET /api/approvals`)의 `approver` 필드에 `approver_name`을, `approver_id`에 로그인 사용자를 함께 저장해 주세요.
3. 403은 "로그인하지 않음/다른 조직" 같은 **진짜 접근 불가**일 때만 써 주세요.

## 유지할 정책

- Critical ≥ 1, High ≥ 2는 승인할 수 없습니다(`block`). 이 경우 approve 요청은 `409`로 거부해 주세요.
- High = 1, Medium ≥ 2는 승인 대상입니다(`block_pending_approval`). 승인하면 `followup_job_id`로 빌드·배포를 이어가 주세요.
